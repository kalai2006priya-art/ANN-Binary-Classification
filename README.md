# ANN Binary Classification Using make_moons Dataset

## Project Overview
This project develops an Artificial Neural Network (ANN) for binary classification using the `make_moons` dataset from Scikit-learn. The model learns to classify data points into two classes using a neural network built with TensorFlow and Keras.

## Objectives
- Generate a binary classification dataset using Scikit-learn.
- Preprocess data using StandardScaler.
- Build and train an ANN model.
- Evaluate the model using classification metrics.
- Visualize the decision boundary, accuracy, loss, and confusion matrix.

## Technologies Used
- Python
- Google Colab
- Scikit-learn
- TensorFlow and Keras
- NumPy
- Matplotlib

## Model Architecture
- Input layer: 2 features
- Hidden layer 1: 16 neurons, ReLU activation
- Hidden layer 2: 16 neurons, ReLU activation
- Hidden layer 3: 8 neurons, ReLU activation
- Output layer: 1 neuron, Sigmoid activation

## Dataset
The `make_moons` dataset contains 1,000 data points divided into two classes. The dataset is split into 80% training data and 20% testing data.

## Evaluation
The model is evaluated using:
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

## How to Run
1. Open the notebook in Google Colab.
2. Run each code cell in order.
3. Observe the evaluation results and graphs.
